## Publicación en GitHub Pages

1. Crear un repositorio en GitHub.
2. Subir estos tres archivos al directorio raíz.
3. Ir a **Settings → Pages**.
4. En **Build and deployment**, seleccionar **Deploy from a branch**.
5. Seleccionar la rama `main` y la carpeta `/ (root)`.
6. Guardar. GitHub generará la URL pública de la página.

Antes de publicar, reemplazar en `index.html` los dos bloques de la sección **Equipo** con los nombres y CV breves correspondientes.
